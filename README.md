# Il grande fantacalcio di Via Balzaretti

Il sito della lega di fantacalcio di Via Balzaretti (Fantaclub, Serie A 2026/27): classifica, rose, calendario, ultima giornata, marcatori, statistiche, quote del bookmaker e albo d'oro.

È una pagina sola (`index.html`), senza dipendenze da installare: GitHub Pages la pubblica così com'è.

I dati sono aggiornati alla data indicata in alto a sinistra nella pagina. Gli aggiornamenti si fanno sostituendo `index.html` con la nuova versione.
